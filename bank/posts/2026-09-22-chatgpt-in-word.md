ChatGPT is now inside Microsoft Word.

OpenAI's release notes for 17 September record a sidebar in Word that drafts from your notes, summarises a document, rewrites a passage and changes headings and formatting. It is on every plan, with the token limits each plan already carries.

Read that alongside the other thing OpenAI shipped this month and it stops being a feature announcement. The Library now reaches SharePoint, Dropbox, Box and Google Drive. So the assistant sits in the document and can see the folder the document came from.

The part worth saying out loud is what this removes. Almost everything that goes wrong with an assistant at a small firm goes wrong in the copying and pasting: the wrong version, the bit that got left behind, the paragraph nobody re-read. A sidebar in the file you already had open removes the step where that happens.

Our read is that most teams should spend the next fortnight on what they already pay for rather than on anything new. The Word sidebar is a good test of that, because if nobody uses it when it is in front of them, a fourth tool was never the answer.
