# bank/

Your material. Everything I draft is built from what is in here, so the posts stay yours and
nothing is invented. Drop things in as they happen; there is no format to learn.

- `moments.md` one line a week. A room, a person, a thing someone said. Date it.
- `stories.md` longer ones, from your own history. Written or a voice note transcribed.
- `numbers.md` anything true about the business this week. Attendees, applications, replies,
  calls booked. A number with a date beside it.
- `photos/` drop images straight in. Filename is the date and three words.
- `voice-notes/` audio is fine. I transcribe and file it.
- `drafts/` anything you wrote yourself that we never posted. Half-finished counts.

The rule: if it did not happen, it does not go in a post. An empty week means the personal slot
takes a value post instead, which is why the value bank exists.
