# viren/

Viren's personal profile. Five posts a week, weekdays, 07:30 to 08:30.

## Where things are

| Path | What it is |
|---|---|
| `plan.md` | the four-week plan: slot, hook, shape, why, what Viren supplies |
| `posts/week-01.md` | this week's five posts, written in full, with the reasoning |
| `posts/*.json` | card specs. `node viren/render.mjs <id>` renders to `out/<id>.png` |
| `carousels/*.json` | carousel specs. `node viren/carousel.mjs <id>` writes `out/<id>.pdf` plus review PNGs |
| `carousels/*.md` | the post copy that goes with each carousel |
| `brand.json` | five rules and the palette |
| `bank/` | Viren's own material: moments, numbers, stories, photos, voice notes |
| `swipe-file.md` | the creator read by mechanism, and the sourced numbers for value posts |
| `references/lara/` | twenty of Lara Acosta's post images, with an index of hook, counts and image type |
| `references/authoredup/` | the 310k-post hook data and eleven worked viral examples |

## The two templates

`tweet` is the conventional card: navy, avatar, name, verified tick, tagline, two or three short
lines. It carries a belief. `file` is a real file shown as a file, for when the artefact is the
point. Photographs of real rooms and people beat both and are used whenever one exists.

## The bar

Before anything is shown to Viren it is scored against the swipe file: opens on a moment or a
claim under forty characters, hands on rather than advice, one exact problem solved completely,
a number with its source and date, nothing invented, no former employer, no assistant, no
question close, no hashtags. A post that fails two rows is not shown.
