## Post

LinkedIn now lets readers flag a post as "seems like AI slop".

Fair. Most of my feed deserves it.

Everything we publish is drafted with Claude, and none of it should read that way. So instead of correcting the same tics every morning, I wrote them into one file that Claude reads before it writes a word. It is called voice.md and the whole thing is in the image.

Sixteen words it may never use. Six shapes it may never build. One test before anything ships: read the first two lines aloud, and if they could sit on any AI account with the name swapped, start again.

The rule that did the most is the least obvious one. No eight single-sentence lines in a row. Vary the paragraph. That change alone is most of the difference between typed and generated.

Copy the file, change the names, drop it in the folder your assistant reads. It took me an evening and it has saved a correction a day since.

## Design notes (from the UI read, 21 Sep 2026)

- One idea per image; the headline is in the post, not on the image (Morphica, 8 Apr 2026:
  text-first, high contrast, one or two accents on a consistent base).
- 24px JetBrains Mono at 1080 wide is 12px at feed width, the floor for a phone. Lines are
  kept under 62 characters so nothing wraps; a wrapped line in a "file" reads as a mistake.
- Three colours only: white for the file name, one warm accent for headings, light blue for
  quoted strings, everything else one grey. The editor chrome (dots, tab) is the only
  decoration and it is what tells the eye "this is real".
- Nothing signed. The post carries the name. A watermark would make it a graphic, and the
  point is that it is not a graphic.
