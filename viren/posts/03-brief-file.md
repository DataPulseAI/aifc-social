## Post

The most expensive line of code is the one nobody asked for.

So nothing gets built at Convu until this file is filled in. Seven headings. It fits on one screen and takes ten minutes, and the whole thing is in the image.

The heading that saves the most is "Who asked". A named person, and the moment they hit the problem. If I cannot fill that line in, the feature is for me, and it waits.

"Done looks like" is the second. The screen, the number or the message that person sees. Never "it works". Half the arguments about whether something is finished disappear when that line was written first.

The last heading is the one nobody writes. "Comes out again if". The condition under which we delete the thing, written while we still remember why we built it.

Copy it. Change the build check to yours. It works whether a person or an assistant is writing the code, because everything it catches goes wrong before anyone opens the editor.
